Артефакти DevOps

  • GitHub Actions: тести, збірка React, збірка Docker-образу
  • Dockerfile, compose.yaml: PHP, два API-симулятори, автоматичні копії бази
  • HTTPS для хмарного сервера: окремий Nginx gateway
  • Автоматичні Node.js та PHP-тести, інтеграційні HTTP-перевірки
  • Моніторинг: ця сторінка та scripts/monitor.mjs
  • Хмарний деплой: захищений workflow для вже наявного Linux-сервера, наприклад AWS EC2

Наявність конфігурації сама по собі не підтверджує успішний запуск GitHub Actions, Docker або AWS. Фактичні результати наведено у звіті.
